Модули

Управление JS-модулями

Модули — обычные папки с JavaScript в config/starredheltix/modules/. Ни архивов, ни шага сборки.

/sh modulesсписок модулей: включённые, выключенные, библиотеки
/sh modules install <имя>скачать и установить из официального репозитория
/sh modules remove <имя>удалить модуль вместе с папкой
/sh modules on <имя>включить (поднимет и зависимости)
/sh modules off <имя>выключить (зависимые — с предупреждением)
/sh modules reload [имя]перезагрузить без перезапуска игры
/sh modules info <имя>детали, включая список зависимых
/sh modules update [имя]обновить с GitHub
/sh modules checkupdatesпоказать модули с обновлениями

Что доступно модулю

📍 Глобальные API

Доступны всем модулям: player, chat, client, settings, camera, math, cps, detector, textComponent, ctjs-классы Display/Text/Image/Scoreboard/Team/Renderer/Maps.

📏 Per-module API

Своё для каждого модуля: events, hud, world, render, inventory, item, gui, keybind, command, config, storage, net, sound, particles, npc.

🔄 Свои команды

command.register("имя", fn) создаёт настоящую Brigadier-команду верхнего уровня. Снимается автоматически при выгрузке модуля.

⚙ Настройки с GUI

config.defineSchema даёт модулю нативные виджеты MoulConfig: переключатели, ползунки, выпадающие списки, цвета и текстовые поля.

📚 Библиотеки

"library": true в metadata + module.exports. Зависимости через requires скачиваются автоматически и сортируются топологически при загрузке.

⏳ Автоочистка

При выгрузке модуля снимаются триггеры, подписки, HUD, батчи, текстуры, шрифты, звуки, таймеры, NPC, команды и локальный HTTP-сервер.

Полный справочник API — scripting-api.md, сжатый референс — scripting-api-AI.md.

Четыре шага

Нужен Minecraft 26.2 и Java 25. Один загрузчик, один вариант мода.

Fabric Loader

Установи для Minecraft 26.2 с fabricmc.net.

Обязательны — без них мод не запустится. Mod Menu поддерживается, но не обязателен.
