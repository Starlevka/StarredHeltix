# StarredHeltix v0.1.0

Fabric мод для Minecraft 1.21.10 (Heltix SkyBlock)

Мод для комфортной игры с QOL фишками и визуальными улучшениями.

---

## 🎯 Основные функции

### Подземелья
- Решатели: Три незнакомца, Криперы-лучи, Крестики-нолики, Этаж 4 (лазеры)
- Таймер кровавой комнаты
- Счётчик смертей и очков
- Авто-готовность

### Бой
- Подсветка мобов (эндермены, пауки, зомби, криперы, волки)
- Slayer HUD

### Фермерство и Лесничество
- HUD скорости Ботинок Ранчера
- Таймер Древоточеца

### Шахтёрство
- Таймеры: Киркобулус и Mining Speed
- Авто-поручения + HUD поручений
- Вейпоинты локаций Гномьих шахт

### Рыбалка
- Уведомление о поклёвке
- Уведомления о выловленной Водяной Гидре

### Skyblock
- SkillHUD, PetOverlay, Museum Helper
- Enchantment Progress HUD
- Equipment Overlay
- Кастомный Scoreboard (Bank, CPS, BPS, Cookie, FPS, Gems, Location, Ping, Purse, Slayer, Title)

### Визуал
- Fullbright, Block Overlay
- Мега-ящики NPC, Диалоги с NPC
- Анимация удара
- Smooth AOTE

### Утилиты
- AutoSprint, Inventory History Log
- Waypoints, Mouse Lock
- Приветствие при входе
- Вход по команде

### Чат
- Пати-команды: !promote, !kick, !invite, !ping, !fps, !time, !coords, !rng, !dt, !boykisser
- Фильтрация сообщений
- Кастомные бинды

### Оптимизация
- Culling: блоки, сущности, частицы
- Оптимизация рендеринга и чанков

### 🎵 Музыкальная система

- Разная музыка в зависимости от локации на сервере.

## ⌨️ Все команды мода

### Основные
```
/sh или /starredheltix — главное меню
/sh reset config — сброс конфига
/sh config password <пароль> — установить пароль для /вход
/sh config readyphrase <фраза> — установить фразу для /яготовлёвал
```

### Фильтры чата
```
/sh filter — меню фильтров
/sh filter add <текст> — добавить фильтр
/sh filter remove <id> — удалить фильтр
```

### Бинды (привязки клавиш)
```
/sh binds — меню биндов
/sh binds create <имя> <команда> — создать бинд
/sh binds delete <имя> — удалить бинд
/sh binds setkey <имя> <клавиша> — назначить клавишу
/sh binds list — список биндов
```

### Другое
```
/sh buttons — редактор кнопок инвентаря
/sh rotation — показать/установить ротацию камеры
/sh hud editor — редактор HUD
/sh update — проверить обновления
/sh update install — установить обновление
/sh coords — показать координаты
/вход — быстрый вход с паролем
/яготовлёвал — сообщение о готовности
```

### Пати-команды (в чате пати/ЛС)
```
!promote / !pt / !повысить — повысить игрока
!kick / !k / !кик — кикнуть из пати
!invite / !inv / !инвайт — пригласить в пати
!ping / !пинг — пинг к серверу
!fps / !фпс — текущий FPS
!time / !время — текущее время
!coords / !координаты — текущие координаты
!rng / !рнг — случайное число (0-100%)
!dt / !дт — сообщение о перерыве
!boykisser — бойкиссер :3
```

## 📦 Установка

1. Установите Fabric Loader для Minecraft 1.21.10
2. Скачайте StarredHeltix v0.1.0
3. Поместите `.jar` в `.minecraft/mods`
4. Установите Fabric API (обязательно), Fabric Language Kotlin (обязательно) и Mod Menu (опционально)
5. Запустите Minecraft с профилем Fabric
