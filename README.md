# ⭐ StarredHeltix ⭐

лЛлЛ Fabric мод для Minecraft с поддержкой 1.21.4 (старый мод) и 1.21.10 (Heltix SkyBlock)

> Мод для комфортной игры с полезными QOL фишками, автоматизацией и визуальными улучшениями

## Основные возможности

### 🎮 Команды в пати и личных сообщениях

Все команды работают через пати чат и личные сообщения с префиксом `!`:

- **!promote / !pt / !повысить** - Повысить игрока в должности
- **!kick / !k / !кик** - Кикнуть игрока из пати  
- **!invite / !inv / !инвайт** - Пригласить игрока в пати
- **!ping / !пинг** - Показать пинг к серверу
- **!fps / !фпс** - Показать текущий FPS
- **!time / !время** - Показать текущее время
- **!coords / !координаты** - Показать текущие координаты
- **!rng / !рнг** - Показать случайное число (0-100%)
- **!dt / !дт** - Сообщение о перерыве
- **!boykisser** - ASCII арт сюрприз

### ⚡ Таймеры и отслеживание

- **Таймер Древоточеца и Джунглиевского топора** - Визуализация КД способностей топоров в лесорубстве (настраивается в секундах)
- **Таймер Киркобулуса** - Показывает КД способности Киркобулуса при шахтёрстве (60 сек по умолчанию)
- **Таймер Увеличения скорости копания** - Показывает КД способности из HOTM (120 сек по умолчанию)
- **Таймер кровавой комнаты** - Отсчет времени в подземельях с уведомлением о готовности

### 🧩 Решатели и автоматизация

- **Three Weirdos (Три незнакомца)** - Автоматическое решение загадки трёх незнакомцев в подземельях
- **Авто-Slayer** - Автоматический звонок Маддоксу при получении опыта убийцы
- **Авто-готовность** - Автоматическое отправление сообщения о готовности в подземельях

### 🛡️ Боевые улучшения

- **Подсветка эндерменов** - Выделение эндерменов с кастомизацией цвета и прозрачности
- **Подсветка криперов** - Выделение заряженных криперов
- **Подсветка волков** - Выделение враждебных волков
- **Анимация удара (БЕТА)** - Изменение позиции и скорости анимации взмаха
- **Fullbright (Яркость)** - Максимальная яркость в игре (Гамма или Окружение)

### � Визуальные улучшения и атмосфера

- **Новогодняя атмосфера** - Праздничный снег и зимние биомы
- **Призрачный NPC** - Интерактивный NPC с диалогами и праздничными сообщениями
- **HUD редактор** - Кастомизируемые элементы интерфейса с визуальным редактором позиций
- **Интеграция ModMenu** - Удобное управление настройками из главного меню Minecraft
- **Оптимизации рендеринга** - Использование современных систем рендеринга для повышения FPS

### 📋 Утилиты и команды

- **Напоминание о голосовании** - Ежедневные уведомления о необходимости голосовать за сервер
- **Автообновление** - Проверка и установка обновлений с GitHub
- **Команды ротации** - Управление направлением взгляда игрока через `/sh rotation`
- **Death Detect** - Автоматическое оповещение команды при вашей гибели
- **Вход по команде (/вход)** - Быстрая авторизация с сохранённым паролем

## Команды в игре

### Основные команды

| Команда | Описание |
|---------|---------|
| `/sh` или `/starredheltix` | Открыть главный конфиг мода |

### Управление конфигом

| Команда | Описание |
|---------|---------|
| `/sh reset voting` | Сбросить напоминание о голосовании (показать его заново) |
| `/sh reset config` | Сбросить конфиг на стандартные значения |
| `/sh config password <пароль>` | Установить пароль для команды `/вход` |
| `/sh config readyphrase <текст>` | Установить фразу готовности для `/яготовлёвал` |

### Управление фильтром сообщений

| Команда | Описание |
|---------|---------|
| `/sh filter add <текст>` | Добавить фильтр сообщений |
| `/sh filter remove <id>` | Удалить фильтр по ID |

### Управление кастомными бинда

| Команда | Описание |
|---------|---------|
| `/sh binds create <имя> <команда>` | Создать новый бинд |
| `/sh binds delete <имя>` | Удалить бинд |
| `/sh binds setkey <имя> <клавиша>` | Привязать клавишу к бинду |
| `/sh binds list` | Показать все бинда |

### Управление ротацией камеры

| Команда | Описание |
|---------|---------|
| `/sh rotation` | Показать текущую ротацию (Yaw и Pitch) |
| `/sh rotation <yaw> <pitch>` | Установить ротацию камеры |

### HUD редактор

| Команда | Описание |
|---------|---------|
| `/sh hud editor` | Открыть редактор HUD элементов |

### Обновление мода

| Команда | Описание |
|---------|---------|
| `/sh update` | Проверить наличие обновления |
| `/sh update install` | Установить найденное обновление |

### Утилиты

| Команда | Описание |
|---------|---------|
| `/sh coords` | Показать и скопировать текущие координаты |
| `/вход` | Авторизация с сохранённым паролем (установить: `/sh config password <пароль>`) |
| `/яготовлёвал` | Отправить сообщение о готовности (если авто-готовность включена) |
| `/d` или `/в` | Быстрый вызов `/dh` |

## Установка

1. Установите Fabric Loader для Minecraft 1.21.10
2. Скачайте последний релиз StarredHeltix
3. Поместите файл мода в папку `.minecraft/mods`
4. Убедитесь, что у вас установлены зависимости:
   - Fabric API
   - Mod Menu (опционально, но рекомендуется)
5. Запустите Minecraft с профилем Fabric

## Системные требования

- Minecraft 1.21.10
- Fabric Loader 0.17.3+
- Fabric API
- Java 21+
