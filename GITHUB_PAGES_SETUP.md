# GitHub Pages Setup

Сайт StarredHeltix уже готов! Чтобы включить его:

## Шаги активации:

1. Перейди на GitHub репозиторий: https://github.com/Starlevka/StarredHeltix

2. Нажми на **Settings** (шестеренка сверху справа)

3. В левой панели найди **Pages** (может быть в разделе "Code and automation")

4. В разделе "Source" выбери:
   - **Branch:** `main`
   - **Folder:** `/docs`

5. Нажми **Save**

6. Подожди 1-2 минуты и твой сайт будет доступен по адресу:
   ```
   https://starlevka.github.io/StarredHeltix/
   ```

## Дополнительно:

Если хочешь добавить кастомный домен:
1. В GitHub Pages settings добавь свой домен
2. Обнови DNS записи у своего хостинга

Готово! Сайт автоматически обновляется при каждом push в репо.
